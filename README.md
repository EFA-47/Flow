# Flow
Match 3 alike Blast game
Aim is to complete all 10 levels, within given move counts. You can blast a group of gems to pop them. There are 3 types of obstacles. Goals are shown on upper section of the view. Blasting a group of gems with more than 5 or more kind will create a bomb. A bomb can blast a 5x5 area upon click or triggered by another bomb. 2 bombs next to each other will create a 7x7 blast area. Ending a level will trigger different types of animation and gif. Game is saved to contiue whichever level was beaten recently.
